# USB в версии0.2 — запасной выход владельца

Существующую основную флешку с `FocusGuardKeys/main-…/private.p8` и `public.json`
можно использовать дальше. Не создавайте новый ключ вместо старого без необходимости.
Проверьте его прежним паролем в новой Windows-программе.

Для новой флешки: «На флешке ещё нет ключа? Создать новый», пароль минимум12символов
в обоих полях, «Создать ключ восстановления». Только съёмный USB-том, без
форматирования и без перезаписи файлов. Создание включает повторное чтение
контейнера и пробную подпись.

Зарегистрируйте только публичные метаданные через обмен FG2-файлами по инструкции
[START_HERE_RU](../START_HERE_RU.md). Приватный файл и пароль телефону/доверенному
человеку не передаются. Верификация публичного файла сама по себе не доказывает
владение USB: регистрация заканчивается только после подписанного ответа.

Назначение USB — начать и через48ч завершить независимую замену доверенного
человека либо разрешение удаления. Доверенному человеку USB не нужен.

Копия флешки обладает теми же правами. При необходимости сделайте побайтовую
копию папки ключа на другой USB и проверьте её новой пробной подписью на другом
Windows-компьютере. Храните пароль отдельно. Работа на реальных USB/Windows
проверяется вручную, сборка наLinux не подтверждает её автоматически.
