# От пустой обычной USB-флешки к проверенному ключу

1. Распакуйте Windows-пакет целиком на ноутбуке. Подключите обычный съёмный USB-том.
   Форматирование не нужно; другие файлы остаются на месте. Если Windows показывает
   USB как fixed disk, мастер его не предложит: используйте носитель с removable
   volume. Буква/label/серийный номер не являются фактором безопасности.
2. В «Настроить USB-ключ» выберите том, проверьте корень и свободное место.
   Выберите «Основной». Задайте и повторите пароль от 12 символов, не сохраняйте
   его рядом с ключом. Нажмите создание. Мастер создаёт новую папку
   `FocusGuardKeys/main-<uuid>` без перезаписи старых ключей.
3. Мастер генерирует P-256 через системный CSPRNG, пишет шифрованный PKCS#8 и
   публичные метаданные, делает Flush, повторное чтение и пробную подпись.
   При ошибке носителя операция считается неуспешной. Не используйте частичную папку.
4. В «Проверить ключ» выберите эту папку, снова введите пароль. Должна пройти
   новая пробная подпись. Неверный пароль и отсутствие USB дают отказ.
5. На тестовом Android сканируйте публичный QR `public.json`, сверьте fingerprint,
   сформируйте запрос регистрации. В Windows «Привязать телефон»: считайте камерой
   либо импортируйте `.fgreq`, проверьте подпись и вручную сверьте fingerprint телефона.
   Подтвердите действие, снова введите пароль, подпишите. Сканируйте ответ телефоном.
   Только успешная проверка и отображение зарегистрированного keyId на телефоне
   завершает привязку. В QR нет приватного ключа.
6. Для аварийного пути доверенный человек **на своём устройстве и отдельном USB**
   явно создаёт ключ с ролью «Аварийный», повторяет проверку и первоначальную
   регистрацию. Если его нет, аварийного пути нет. Основной не может его заменить.
7. Для резерва подключите второй USB. «Проверить ключ» → выберите источник и другой
   том, подтвердите, что копия имеет те же права, создайте резерв. Проверяются hash
   файлов и metadata; затем вручную проверьте пароль/подпись резервной папкой.
8. Перенесите резерв на другой Windows 11 ноутбук, распакуйте там программу, без
   исходного ноутбука и без сети расшифруйте контейнер и выполните новый запрос
   enrollment на тестовом телефоне (первоначальная привязка) либо допустимый новый
   защищённый запрос. В последнем случае Windows попросит отдельно сверить
   существующий fingerprint из общего заголовка телефона; новый enrollment на
   активированном телефоне не нужен и не разрешается. Сверьте fingerprint заново.
   DPAPI не используется, ключ должен быть переносим; реальный результат заносится
   в TEST_REPORT, не предполагается по наличию теста библиотеки.

Храните оригинал, резерв и пароль раздельно. Копия обычной флешки предоставляет те
же полномочия. Программа не может запретить копирование. Файл на профиле/локальном
диске не считается USB-ключом в обычной программе. Модифицированный Windows-клиент
и администратор Windows вне модели угроз.

При каждой подписи файл читается заново. Извлечение, обнаруженное до публикации
ответа, отменяет операцию. Уже выданный ответ остаётся действительным до окончания
15-минутного challenge либо его потребления/отмены/перезагрузки на телефоне.
Не рассчитывайте, что извлечение отзовёт показанный QR. Пароль не заменяет носитель.
