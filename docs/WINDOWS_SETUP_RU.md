# Windows 0.2 — только флешка восстановления

Распакуйте Windows ZIP целиком и откройте `FocusGuard.KeyConsole.exe`.
.NET включён, отдельная установка не нужна. Нужна Windows11 x64.
EXE без Authenticode; сверяйте источник и SHA256 из поставки.

Программа больше не занимается повседневной разблокировкой. Для этого есть
Android-приложение доверенного человека и WhatsApp.

1. Подключите свою флешку. Нажмите «Обновить список», выберите носитель и main-папку.
2. Введите пароль и нажмите «Проверить флешку».
3. Для первоначальной регистрации нажмите «Сохранить публичный файл для телефона».
4. На телефоне создайте запрос регистрации/восстановления и сохраните файл дляПК.
5. Откройте файл кнопкой «Открыть файл запроса». При первом подключении сверьте
   идентичность с нижней частью экрана телефона. Проверьте название действия.
6. Поставьте галочку, введите пароль заново и нажмите подтверждение с сохранением.
7. Передайте файл обратно телефону и примените его в Focus Guard.

Начальный запрос запускает48ч после применения; точка отсчёта — issued принятого
начального запроса. Телефон можно выключать; часыПК не сокращают ожидание.
После48ч нужен свежий запрос завершения и та же флешка. Без подтверждённого
сетевого времени телефон не объявляет ожидание завершённым.

Если ключа ещё нет, раскройте «Создать новый». Пароль от12символов в обоих полях.
Носитель не форматируется, существующие ключи не перезаписываются.
Ключи emergency старой версии в новую программу восстановления не подставляются.
Полная инструкция — [START_HERE_RU](../START_HERE_RU.md).
