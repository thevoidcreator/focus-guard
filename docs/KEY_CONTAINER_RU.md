# Контейнер USB v1

`FocusGuardKeys/main-<uuid>/private.p8` — DER EncryptedPrivateKeyInfo PKCS#8.
`public.json` — containerVersion=1, role=main/emergency, keyId, publicSpki, createdUtc.
PKCS#8: PBES2 (1.2.840.113549.1.5.13), PBKDF2 (1.2.840.113549.1.5.12),
PRF HMAC-SHA256, 600000 итераций, случайная соль библиотеки .NET, AES-256-CBC
(2.16.840.1.101.3.4.1.42), случайный IV. Ключ ECDSA secp256r1 генерирует ECDsa.Create.
Формат выбран стандартной .NET ExportEncryptedPkcs8PrivateKey; собственного KDF нет.
Импорт через ImportEncryptedPkcs8PrivateKey; plaintext и DPAPI-only копии не создаются.

Шифрованный PKCS#8 .NET успешно прочитан Python cryptography в проверке среды.
Проверка на втором Windows-ноутбуке требует настоящего носителя и остаётся ручной.
Программа проверяет присутствие removable volume перед/после криптографии, каждые
75 мс во время операции и повторно читает файл. Это наблюдение ОС, не аппаратная
аттестация флешки. Возможны границы обнаружения очень короткого unplug/replug.
Уже опубликованный ответ остаётся действительным до TTL/потребления на телефоне.

Пароль вводится заново в PasswordBox, извлекается из SecureString в временный char[],
очищаемый после операции; BSTR освобождается ZeroFreeBSTR. Системные объекты ECDsa
dispose; encrypted buffers очищаются. Не обещаем гарантированное стирание managed
memory или защиту от дампа процесса/администратора. Ключ не передаётся Android и не
пишется в профиль, реестр, clipboard, логи. В LocalAppData хранятся лишь публичные
идентичности телефонов.

Папка назначения всегда новая, FileMode.CreateNew, без форматирования. После записи
Flush(true), повторное чтение, расшифровка и пробная подпись. Сбой может оставить
незавершённую новую папку; существующие ключи не затрагиваются. Проверить её перед
использованием. Копия контейнера имеет те же права, серийный номер/буква диска не
считаются фактором безопасности. Ссылки/reparse points в путях подписания запрещены.
