# Android: только тестовое устройство

Цель владельца: Nothing Phone (3a), Android/Nothing OS уточнить перед испытаниями.
Минимум API31, compile/target36. Поддержка конкретной модели **не подтверждена**.
Образ Google APIs API31 r14 не прошёл deprovisioning: `Unknown URI content://telephony/carriers/enforce_managed`, затем зависший admin. На нём не включать жёсткие политики. Журнал — TEST_REPORT.md.

## Сначала резервные копии и проверенный выход

Сохраните фото/файлы/контакты/SMS/резерв WhatsApp, коды восстановления аккаунтов,
VPN-профили, данные аутентификаторов и сведения eSIM безопасным поддерживаемым
способом. Проверьте восстановление копий. Создайте основной USB, резерв на другом
носителе и отдельно аварийный ключ доверенного человека. Пройдите реальную подпись
и верификацию до активации. Само наличие флешки не означает рабочего ключа.

На основном телефоне не выполняйте factory reset/provisioning. Подготовка Device
Owner обычно требует нового/сброшенного аппарата без аккаунтов; сброс выполняет
владелец отдельно после резервных копий, он никогда не запускается приложением.

## Лабораторный provisioning

1. Создайте отдельный Android API31+ AVD либо возьмите телефон без личных данных.
2. Соберите `app-lab-debug.apk`, установите через `adb install -t APK`.
3. Только на выбранном тестовом serial выполните:

```sh
adb -s TEST_SERIAL shell dpm set-device-owner ru.focusguard.android.lab/ru.focusguard.android.AdminReceiver
```

4. Откройте Focus Guard. До активации сверяйте список установленных приложений:
   название, packageId, SHA-256 signing certificate. WhatsApp и каждый вариант
   v2rayNG/Happ/v2RayTun/Incy выбирайте по доверенному источнику и сертификату.
   Не выбирайте пакет по похожему названию. Отсутствующие приложения сначала установите.
   Обновление с signing lineage сохраняет исключение, чужой сертификат — нет.
5. Сканируйте публичные метаданные USB с Windows, выберите main/emergency, сверьте
   fingerprint и создайте enrollment challenge. ПК сканирует QR телефона, сверяет
   его fingerprint, подписывает ответ. Телефон сканирует и применяет ответ.
   При необходимости повторите для независимого аварийного ключа.
6. Перед жёсткой защитой выполните smoke test provisioning/deprovisioning на AVD,
   затем повторите на тестовом Nothing. Lab debug помечен testOnly; это позволяет
   лабораторное ADB-восстановление **только пока ADB ещё доступен**.
7. Только после проверки лабораторного выхода включите явный checkbox и кнопку
   лабораторной защиты. Активация выключает отладку через user restriction. Не
   рассчитывайте на ADB как аварийный путь после этого. Публичный production APK
   не активируется — модельного адаптера промышленного выхода пока нет.

## Повседневный режим

Звонки, SMS, контакты и клавиатура определяются по системным handlers/службам;
системные пакеты целиком не приостанавливаются. VPN — ручной запуск выбранного
клиента, без always-on/lockdown по умолчанию; одновременно несколько VPN ОС не ведёт.
Wi-Fi WPA2-PSK добавляется через небольшой DO-интерфейс. Bluetooth имеет отдельные
кнопки включения/поиска/сопряжения с runtime permissions. OEM-диалоги нужно испытать.
Полный Settings не разрешён. Wi-Fi Enterprise, captive portal и OEM pairing пока
не имеют подтверждённого пользовательского пути.

Сеанс не требует ПК/пароля/USB/интернета. Вопрос → 60 секунд → отдельное подтверждение.
Отмена до старта бесплатна; досрочное завершение сжигает остаток. Экран не останавливает
elapsedRealtime. День с 04:00 в сохранённой Europe/Moscow (изменение через flow).
Reboot сжигает сеанс, не обнуляет cooldown, аннулирует challenges. 48 часов ожидания
копятся только по подтверждённым интервалам текущего boot. Утерянный после power-off
интервал не засчитывается. Неправильная дата закрывает новый сеанс; восстановление
через 24 часа непрерывной стабильной работы с автоматическим временем описано в ADR.

## Файлы и QR

Предпочтительно камера встроенного сканера. Для ПК без камеры экспортируйте `.fgreq`
на телефоне, перенесите обычным способом без отладки; импортируйте файл в Windows,
экспортируйте `.fgres` и импортируйте на телефоне. File picker временно допускается
только на время операции; возвращённый файл читается как ограниченный протокол,
16 KiB. Пользовательский файловый менеджер не становится постоянным исключением.
На OEM отдельно проверить, что SAF/его дополнительные действия не открывают обход.

## Проверки до допуска Nothing Phone (3a)

- Device Owner, HOME, keyguard/PIN unlock, входящий/исходящий вызов, SMS, контакты.
- Экстренный dialer — без реального звонка в экстренную службу при испытании.
- WhatsApp включая звонки/уведомления; каждый фактический VPN и выбор после reboot.
- Screen-off/Doze до истечения сеанса, процесс убит, reboot, граница 04:00/12 часов.
- Share, ссылки, WebView, files, installer, assistant/search, recent apps, уведомления,
  permission dialogs; удаление DPC/новый пользователь/Settings недоступны и в сеансе.
- Полный цикл снятия: прерывание на каждом этапе, повтор, отсутствие DO/admin,
  обычный HOME, доступность пакетов, личные файлы/контакты/SMS/WhatsApp сохранены.
- OS/app updates. Автообновление разрешённого приложения допустимо с signing lineage;
  ручная установка/диалоги установщика и OEM обновления требуют отдельного испытания.

Запишите build fingerprint, версии ОС/приложений, пакеты/сертификаты, результат и
доказательства. Без этого основной аппарат не принят.
