# Focus Guard — поставка 0.1.0

Это лабораторная реализация. **Не устанавливайте Device Owner на основной Nothing
Phone (3a): снятие управления без потери данных на этой модели не подтверждено.**
Production activation намеренно заблокирована. Сброс не считается безопасным выходом.
На образе Google APIs Android12/API31 полный тест снятия завершился системной
ошибкой telephony provider; этот образ также не допущен к жёсткой активации.

- `FocusGuard-source.zip` — полный монорепозиторий, русские инструкции, тесты,
  протокол/векторы, build scripts/CI и свидетельства проведённых проверок.
- `FocusGuard-lab-debug.apk` — подписанный testOnly APK для эмулятора/отдельного
  тестового аппарата. Обычная установка через ADB требует `-t`. Жёсткие политики
  включаются вручную после регистрации рабочего ключа и проверки выхода.
- `FocusGuard-production-disabled-unsigned.apk` — собранный unsigned release
  с закрытой активацией; не готовый для основного телефона релиз.
- `FocusGuard-Windows-win-x64.zip` — распакуйте целиком, запустите
  `FocusGuard.KeyConsole.exe`. Включены .NET/WindowsDesktop runtime 10.0.13
  и native camera DLL. Администратор/USB-драйвер не нужны. EXE без Authenticode.
- `TEST_REPORT.md` — фактические результаты и оставшаяся приёмка.
- `SHA256SUMS.txt` — контрольные суммы файлов поставки.

В исходниках начните с README.md и docs/RECOVERY_RU.md, затем USB_KEY_SETUP_RU.md
и ANDROID_SETUP_RU.md. Обычная флешка копируется, резерв обладает теми же правами.
Аварийный ключ создаётся и хранится независимо у доверенного человека.

Подтверждены сборки и автоматические проверки. Реальные Nothing/Windows/USB/камеры
не испытаны; эти результаты нельзя предполагать по unit-тестам.
