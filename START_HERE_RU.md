# Windows 0.3: пошаговый мастер и коды вместо файлов

Откройте FocusGuard.KeyConsole.exe из полностью распакованного ZIP0.3.
Тёмная тема с зелёными акцентами включена по умолчанию; переключатель сверху
позволяет выбрать светлую. Тема сохраняется локально.

## Подготовка пустой или отформатированной флешки

1. Нажмите «Подготовить флешку». Выберите съёмный носитель → «Продолжить».
2. Придумайте пароль не менее12символов и повторите в соседнем поле →
   «Создать и проверить ключ». Флешка не форматируется, файлы не перезаписываются.
   Если уже есть один main-ключ, мастер предложит проверить прежний пароль.
3. Нажмите «Скопировать приглашение», отправьте текст себе в мессенджере.
4. На Redmi скопируйте текст сообщения → Focus Guard → «Вставить код».
   Выше появится регистрацияUSB. Сверьте идентичность и создайте запрос регистрации.
5. На Redmi «Скопировать запрос» → отправьте текст обратно наПК.
6. НаПК «Дальше: запрос с телефона» → «Вставить и проверить запрос».
   При первом подключении сверьте идентичность телефона. Проверьте действие,
   поставьте галочку и введите пароль флешки заново → «Подтвердить флешкой».
7. Нажмите «Скопировать ответ» и отправьте текст на Redmi.
8. На Redmi скопируйте ответ → «Вставить код» → «Применить подтверждение».
   Проверьте строку «Флешка восстановления: настроена». До неё регистрация не закончена.

Приватный ключ не передаётся. Все копируемые сообщения — публичные метаданные
или подписанные протокольные сообщения. Поле кода может показывать JSON: его
не надо редактировать, нужно копировать всё сообщение целиком.

## Восстановление

«Восстановить доступ» → заменить доверенного человека либо снять управление
для удаления → флешка и пароль → код запроса с телефона → проверка/подпись →
код ответа для телефона. Можно также открыть запрос/сохранить ответ файлом.

Запрос начала и запрос завершения48ч создаются телефоном отдельно.
Мастер принимает только выбранное действие и соответствующий main-ключ.
Отсчёт и интернет-проверка48ч остаются на телефоне. После подготовки ответа
ПК не заявляет, что телефон уже применил его: итог надо проверить на телефоне.

Если на носителе несколько main-ключей, мастер останавливается с объяснением,
чтобы не подписать другим ключом. Используйте носитель с одним нужным ключом;
не удаляйте старые ключи без резервной копии. Полноценный выбор нескольких
дружественно названных ключей остаётся ограничением этой версии.

## Обновление Android

Для работы с кодами нужны APK0.3 на обоих телефонах. ApplicationId и подписи
сохранены. Ставьте поверх старой установки, не очищайте данные и не удаляйте
приложения: Keystore-идентичности и существующая привязка сохраняются.
Ваш phone-lab: `adb install -r -t FocusGuard-0.3-phone-lab.apk`.
Guardian0.3 поддерживает Android11+, устанавливается обычным обновлением APK.
Приглашения и ответы WhatsApp отправляются текстом. Файловый импорт принимает
любой MIME-тип, но содержимое и подпись по-прежнему проверяются строго.
QR в этой реализации не добавлен: основной канал — копирование текста.

логи в verification/v03. Новый WPF-интерфейс на реальном Windows здесь не запускался.

ваших тестовых устройствах. Предыдущие ограничения учёта/снятия управления
из TEST_REPORT_V02.md сохраняются. Production activation закрыта.
