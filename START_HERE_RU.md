# Focus Guard 0.2 — начните здесь

Это новая лабораторная версия, не прошедшая аппаратную приёмку Redmi A3 Pro /
Nothing Phone (3a) Android16. Сначала отдельный тестовый телефон. Не включайте
защиту на основном телефоне, пока не проверен полный выход без потери данных.

## Что скачать

- Вам на тестовый телефон: `FocusGuard-0.2-phone-lab.apk`.
- Доверенному человеку: `FocusGuard-0.2-guardian.apk`.
- Вам на Windows11 x64: `FocusGuard-0.2-Windows-win-x64.zip`.

Сверьте SHA256 с `SHA256SUMS.txt`. ZIP распаковывается целиком; запустить
`FocusGuard.KeyConsole.exe`. Runtime включён. Windows EXE без Authenticode.

APK подписаны одним лабораторным debug-сертификатом этой сборки. Исходный
сертификат прежнего APK в среде отсутствует: установка поверх старой версии
может завершиться INSTALL_FAILED_UPDATE_INCOMPATIBLE. Не удаляйте активного
Device Owner и не очищайте его данные. Сначала штатно снимите старое управление.
На тестовом устройстве без активированной защиты удалите старый APK обычным
способом и установите новый. USB-флешка при этом остаётся пригодной.
Если даже без включённой защиты прежняя версия уже назначена Device Owner,
обычное удаление может быть запрещено. На отдельном тестовом телефоне со старой
lab/testOnly-сборкой и доступным ADB сначала снимите её admin штатной командой:

```sh
adb -s TEST_SERIAL shell dpm remove-active-admin ru.focusguard.android.lab/ru.focusguard.android.AdminReceiver
```

Проверьте успешное снятие, затем удалите старый APK. Для активной защиты с
запрещённым ADB используйте прежний защищённый выход, не очищайте данные.
Если обновление тем же сертификатом уже установлено поверх активной0.1, новый
интерфейс сохраняет отдельный экран прежнего восстановления: экспорт FG1-запроса,
применение ответа Windows0.1 и повтор незавершённого снятия. Это не миграция
активных ограничений в новую схему.
Установка phone-lab через ADB: `adb -s TEST_SERIAL install -t FocusGuard-0.2-phone-lab.apk`.
Guardian ставится обычной установкой APK. Телефон доверенного человека не требует
Device Owner, сброса, отладки или специальных разрешений на SMS/уведомления.

## 1. Настройте ваш тестовый телефон

В Focus Guard откройте «Лимит и постоянные исключения». Оставьте 120 минут,
выберите установленный WhatsApp и свои Incy/Happ/v2rayNG/v2RayTun. Сохраните.
Вызовы, SMS, контакты и необходимые системные компоненты добавляются автоматически.
Похожие названия приложений не считаются подтверждением их происхождения.

Разрешите учёт использования, доступ к фоновому воспроизведению (системный доступ
к уведомлениям) и уведомление об учёте. Содержимое уведомлений приложение не
сохраняет и не пересылает. Разрешения нужны для учёта экрана и аудио.
Нажмите «Проверить время через интернет».
Если Android запрещает включить доступ для APK, откройте системный экран
«О приложении» и проверьте пункт «Разрешить ограниченные настройки»; подготовьте
разрешения до включения защиты.

## 2. Свяжите доверенного человека

1. Она запускает «Focus Guard — Подтверждение» и нажимает «Отправить приглашение
   через WhatsApp». На её телефоне должен быть настроен PIN-код блокировки.
2. Вы открываете полученный документ в Focus Guard. Если WhatsApp не предлагает
   приложение, сохраните документ и используйте «Открыть полученный файл».
3. В настройке появляется контрольная фраза. Создайте запрос привязки и отправьте
   его через WhatsApp. Создание нового запроса заменяет предыдущий.
4. Она открывает запрос в приложении подтверждения. Созвонитесь и сравните фразу
   на обоих телефонах. Если не совпадает — не подтверждать.
5. Она ставит галочку, подтверждает PIN-кодом своего телефона и отправляет ответ.
6. Вы открываете ответ и нажимаете «Применить подтверждение». Статус — «подключён».

Обычные запросы идут так же: «ещё 1 час», «до 04:00», «разрешить удаление».
Файл — публичный подписанный документ, не приватный ключ. Любой ответ одноразовый,
действует только для исходного запроса и связанного телефона. На смене дня
незавершённые запросы отменяются; при необходимости создайте новый.
Отказ просто не выдаёт разрешение; уведомление об отказе автоматически не отправляется.

## 3. Подключите вашу основную флешку восстановления

1. Распакуйте Windows ZIP и запустите `FocusGuard.KeyConsole.exe`.
2. Подключите вашу существующую флешку. Выберите её и папку `main-…`.
3. Введите прежний пароль и нажмите «Проверить флешку».
4. Нажмите «Сохранить публичный файл для телефона». Передайте этот файл телефону.
   Не передавайте `private.p8` и пароль.
5. В Focus Guard откройте публичный файл, сверьте идентичность с Windows,
   нажмите «Создать запрос регистрации флешки» → «Сохранить запрос для ПК».
Для переноса файлов между своим телефоном и ПК можно использовать собственный
чат WhatsApp и WhatsApp Web на ПК: отправьте запрос себе и скачайте документ
в браузере. Ответ ПК отправьте себе тем же способом. USB debugging для этого
не требуется; не рассчитывайте на переключение USB-режима через закрытые Settings.

6. На ПК откройте этот запрос, сверьте телефон и действие, введите пароль,
   поставьте галочку и нажмите «Подтвердить флешкой и сохранить ответ».
7. Откройте ответ телефоном → «Применить подтверждение». Статус флешки — «настроена».

Если основной флешки ещё нет, создайте её через раскрывающийся пункт Windows.
Это не форматирует носитель. Пароль минимум12 символов в обоих полях. Храните
флешку и пароль отдельно. Обычная флешка копируется; её копия имеет те же права.

## 4. Системная блокировка — только после проверки на тестовом устройстве

Обычная установка APK не назначает Device Owner. На подготовленном тестовом
устройстве без конфликтующего управления/аккаунтов используйте:

```sh
adb -s TEST_SERIAL shell dpm set-device-owner ru.focusguard.android.lab/ru.focusguard.android.AdminReceiver
```

Не запускайте factory reset автоматически. Если назначение не разрешено,
разберите причину, не удаляя личные данные. Проверьте provisioning/deprovisioning
на выбранной тестовой модели до включения повседневных ограничений.
Активация ограничивает отладку; после неё нельзя рассчитывать на ADB как на выход.

## 5. Независимое восстановление без доверенного человека

Выберите на телефоне «Заменить доверенного человека •48 часов» или
«Удалить Focus Guard •48 часов». Сохраните запрос для ПК, подтвердите флешкой
и примените ответ телефоном. Отсчёт идёт с времени создания принятого начального
запроса, а не с момента первого открытия экрана. Выключение/перезагрузка
не останавливают 48 календарных часов. Защита продолжает работать.

Через48 часов нажмите «Завершить через флешку», подтвердите свежий запрос той же
флешкой и примените ответ. Нужен доступ к двум источникам сетевого времени.
Для замены появится привязка нового доверенного человека; старый больше не
подтверждает запросы. Для удаления сначала выполняется системное снятие управления.
При ошибке показывается этап и кнопка повторения; успех не объявляется заранее.

## Важные ограничения тестовой версии

- WhatsApp разрешён целиком, включая каналы/статусы/видео. Это сознательное исключение.
- Источники времени: `dl.google.com`, `builds.dotnet.microsoft.com`; свой сервер не нужен.
- Некоторые плееры не публикуют MediaSession. Если источник музыки определить
  невозможно, время учитывается консервативно. Это может затронуть неизвестное
  аудио разрешённого приложения. Фактическое поведение WhatsApp необходимо проверить.
- Обычный Android не даёт DPC универсального точного определения источника любого
  аудио. Поведение неизвестных плееров, PiP, Doze и OEM требует ручной приёмки.
- Доступ к сети/смене Wi-Fi при жёсткой блокировке зависит от уже настроенной сети;
  полный Android Settings не открыт. Подготовьте сеть и VPN до активации.
- В 0.2 нет SMS, сервера, уведомлений своего бота и автоматического ответа.
