# Focus Guard0.3

Windows: новый пошаговый мастер, тёмная/светлая тема с зелёными акцентами.
Телефоны: копирование/вставка кодов, WhatsApp передаёт текст вместо JSON-файлов.

- [Windows ZIP](FocusGuard-0.3-Windows-win-x64.zip?raw=true): распаковать целиком, открыть FocusGuard.KeyConsole.exe.
- [Ваш Redmi APK](FocusGuard-0.3-phone-lab.apk?raw=true): обновление через `adb install -r -t`.
- [Доверенный телефон APK, Android11+](FocusGuard-0.3-guardian-android11.apk?raw=true): обычное обновление APK.
- [Исходники](FocusGuard-0.3-source.zip?raw=true).

Не удаляйте приложения и не очищайте данные: подписи сохранены, привязки сохраняются при обновлении поверх.
[Порядок действий](START_HERE_RU.md). [Ограничения](KNOWN_LIMITATIONS_RU.md).
Новый UI/WhatsApp-обмен требуют проверки на тестовых устройствах. На основной Nothing пока не активировать.
Используйте Download raw file, если GitHub показывает страницу файла вместо скачивания.
